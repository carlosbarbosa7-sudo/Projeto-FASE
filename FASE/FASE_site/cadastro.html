Solicitar cadastro

Informe os dados da organização e da pessoa responsável. Se aprovada, a instituição receberá uma conta com senha provisória para acessar o sistema.

Ambiente local de desenvolvimento: a solicitação será salva no banco e ficará pendente para análise. Use dados fictícios; ainda não informe dados reais.

▣

O que acontece depois?

A equipe FASE confere as informações da organização. O acesso para publicar só deve ser liberado após aprovação administrativa.

Se aprovada, a organização recebe acesso por e-mail e uma senha provisória criada pelo administrador. No protótipo local, a entrega dessas credenciais é manual.
