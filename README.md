# FASE — Força de Aprendizagem, Suporte e Empregabilidade

Protótipo de plataforma para divulgação de oportunidades, com site estático, API Spring Boot e banco MySQL.

## Estrutura

- `FASE/FASE_site`: páginas HTML, CSS e JavaScript.
- `FASE/api`: API Java/Spring Boot.
- `FASE/database`: esquema, migração e dados demonstrativos.
- `FASE_Projeto_Interdisciplinar_Revisado.docx`: relatório do projeto.

## Executar localmente

Consulte `FASE/api/README.md` e `FASE/database/README.md` para requisitos e instruções detalhadas. A API requer Java 25, Maven e MySQL 8.0.16 ou superior. O arquivo `FASE/database/seeds/001_oportunidades_demonstracao.sql` contém registros fictícios para desenvolvimento local.

Não use os dados demonstrativos como dados reais nem exponha a API publicamente sem implantação segura.
